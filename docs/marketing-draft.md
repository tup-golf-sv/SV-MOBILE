## 3. 20초 실제 화면 시연 — 촬영·편집 지시

생성 영상이나 합성 성공 장면을 사용하지 않는다. 검증된 Android 실기기 화면을 직접 녹화하고, 실제 사람의 촬영 동의를 받은 동일 테스트 세션을 사용한다. 아래 각 기능이 실기기에서 통과하기 전에는 해당 장면을 광고로 공개하지 않는다.

| 시간 | 실제 촬영 화면 | 자막 | 내레이션 |
| --- | --- | --- | --- |
| 0–3초 | 휴대폰에서 SV MOBILE 실행 | 내 스윙, 휴대폰으로 다시 보기 | 내 스윙을 직접 확인하세요. |
| 3–8초 | 카메라 연결 후 실제 스윙과 감지 결과 | 촬영부터 스윙 감지까지 | 휴대폰을 고정하고 스윙하면, |
| 8–13초 | 방금 촬영한 영상의 실제 리플레이 | 방금 한 스윙을 리플레이 | 방금 한 동작을 다시 보고, |

영상 전체에 읽을 수 있는 크기로 `개발 중 · 비공개 테스트`를 유지한다. 실제 화면을 20초에 맞춰 편집하되 처리 시간을 줄인 장면에는 `일부 구간 편집`을 표시한다. QR 목적지가 없거나 설치가 검증되지 않으면 마지막 화면은 `내부 시연 · 배포 전`으로 바꾸고 QR을 빼며, 외부에 공개하지 않는다. PRO·가격·구독 성공 화면은 실제 검증 전 시연에 넣지 않는다.
