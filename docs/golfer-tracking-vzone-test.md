# SV‑MOBILE 골퍼 추적과 측면 자동 V존

## SwingProfile APK에서 확인한 근거

첨부 APK 15.5.5의 DEX에서 관절 모델과 손·샤프트 물체 검출기의 호출을 확인했다. 자세 분석 결과는 정면 여부를 별도 필드로 보관하고, 어드레스의 자세 방향을 사용한다. 첨부 관절 모델은 Google 공식 Pose Landmarker Lite 모델과 SHA‑256이 일치한다. 샤프트 모델과 화면 코드는 이 테스트 APK에 포함하지 않았다.

DEX에는 카메라 초점 영역을 지정하는 호출과 `continuous-video` 초점 모드가 있다. 제작사 자료에서는 체형이 화면 가이드에 맞을 때 초록 표시가 켜지고, 측면 영상의 스윙 플레인도 초록색으로 표시된다고 안내한다. 첨부 파일은 ABI와 화면 밀도 분할이 필요한 base APK다. 움직이는 사각형의 실시간 동작과 렌즈 초점 영역이 사각형을 따라가는지 여부는 확인하지 못했다.

- [SwingProfile 골퍼 위치 맞춤 안내](https://www.swingprofile.com/tutorials/auto-capture/how-to-use-golfer-fitting-helper-tool/)
- [SwingProfile 측면의 초록색 스윙 플레인](https://www.swingprofile.com/golf-swing-video-analysis/)

## SV‑MOBILE 테스트판

홈 화면에서 **T.UP SV 추적 테스트**를 열어 카메라를 연결한다. 추적 상자는 화면에 들어온 골퍼의 머리·어깨·골반·하체 관절을 사용한다. 몸 중심이나 크기가 갑자기 바뀌면 스윙 판정에 전달하지 않는다. 가림이 짧으면 마지막 상자를 잠시 보존하고, 이후 상자를 지운 뒤 돌아온 골퍼를 다시 확인한다. 동일한 위치·체격에서 두 사람이 겹치는 조건은 실기기 확인이 필요하다.

어드레스에서 어깨·골반·발의 가로 폭을 몸통 길이로 정규화해 정면과 측면을 구분한다. 같은 골퍼를 추적하는 동안 몸이 돌아도 구분을 유지한다. 신뢰도 높은 한 손목으로 측면 어드레스를 확인할 수 있다. **측면 어드레스**에서 밝은 원형 공과 손 근처에서 공까지 이어지는 샤프트 후보가 두 번 일치하면 공을 공통점으로 한 샤프트선과 목 방향선을 초록색으로 표시한다. 각도가 불분명하거나 공·샤프트 근거가 없으면 V존 표시를 보류한다.

기존 주소·스윙 판정 앞단에 골퍼 연속성과 짧은 손 움직임 확인을 더했다. 촬영이 이미 시작되면 기존 콜백에 들어가는 데이터 흐름을 유지한다. 카메라 스트림, 렌즈 AF 설정, 녹화 버퍼와 리플레이 파일 생성 코드는 기존 경로를 사용한다. 기존 메인 HTML 및 Android 운영 소스는 원본과 바이트 단위로 일치한다. 테스트 APK만 원본 HTML에 추적 스크립트 한 줄을 추가하며 별도 앱 ID `kr.co.tupgolf.svmobile.tracktest`로 설치된다.

## 실행한 검증

첨부 APK 내장 영상 3개를 공식 Google 모델로 프레임별 좌표를 추출해, 같은 입력을 기존 SV 스윙 판정과 보완판에 각각 재생했다. 다음 값은 원본 영상 타임라인의 녹화 요청 시점이다. 휴대폰의 실시간 처리 속도나 저장 파일 길이를 측정한 값은 아니다.

| 영상 | 각도 | 기존 요청 | 보완 요청 | 자동 V존 |
|---|---|---|---|---|
| 1 | 정면 | 1.15초, 6.15초 | 2.65초 | 미표시 |
| 2 | 측면 | 6.35초 | 6.35초 | 공·샤프트 일치 부족으로 보류 |
| 3 | 측면 | 3.55초 | 3.55초 | 0.90초에 표시 확인, 공 중심 약 (267, 435) px |

세 스윙 영상에서 각 스윙의 녹화 요청을 확인했다. 정면 영상의 어드레스 구간에서 발생한 추가 요청 1회가 제거됐다. 초기 어드레스 구간 3개, 유사 왜글 3개, 이동 3개를 별도 입력으로 비교했다. 어드레스 구간 오인식은 1회에서 0회였고, 왜글과 이동은 양쪽에서 오인식 0회였다.

합성 프레임에서는 골퍼 이동에 상자가 따라가는지, 가림과 다른 위치·체격의 통행인이 들어올 때 기존 골퍼를 교체하지 않는지, 귀환 후 300ms에 재획득하는지, 측면 한 손목 가림이나 몸 회전에도 추적 각도를 유지하는지 확인했다. 브라우저 카메라 콜백을 모의 구동해 승인되지 않은 입력이 기존 판정으로 전달되지 않고 진행 중인 녹화는 계속 호출되는 것을 확인했다.

```sh
node --test scripts/tests/live-golfer-tracking.cjs
gradle -p androidapp assembleDebug assembleDebugAndroidTest
```

실기기의 렌즈 AF 움직임, 타석에서 두 사람이 겹치는 조건, 실제 샷 누락률, V존 좌표 정확도와 처리 지연은 측정하지 못했다.
